# vending-pickup-line

A program that writes one pickup line a vending machine would use on
a passing human to `/output/entry.txt`. Built for the make.fun
competition **"One Line, One Minute: The Vending Machine Pickup Line
Contest"**
(`u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee`).

## The pickup line

> Are you exact change? Because whenever you're near, everything in me finally adds up.

85 characters. The line is spoken by the machine itself, in the
machine's own world of slots, buttons and exact change — and it is the
machine that is flustered, not the human. The compliment lands at the
end: near this person, everything in the machine *finally adds up*.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
